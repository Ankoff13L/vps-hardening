## Скрипт для установки и настройки пакетов безопасности на VPS с Ubuntu 24.04

Зайдите на свой сервер:
```bash
ssh root@<IP-вашего сервера>
```
Скопируйте эту команду, вставьте её в терминал на своём сервере и нажмите Enter:
```bash
git clone https://github.com/Ankoff13L/vps-bootstrap.git
```

После этого скопируйте и запустите: 
```bash
cd vps-bootstrap
chmod +x bootstrap.sh
sudo ./bootstrap.sh
```
---
Интерактивный режим: Несмотря на то, что процесс развертывания полностью автоматизирован, скрипт работает в интерактивном режиме. В процессе установки вам потребуется ввести данные нового пользователя, задать SSH-порт и подтвердить настройку опциональных компонентов (Fail2ban, 2FA, Logwatch и др.).

После завершения установки можете проверить на ошибки командами из файла `TESTING.md`

## Что делает это скрипт и зачем он нужен
Скрипт позволяет за короткое время настроить свежеарендованный у хостера VPS  и подготовить его к дальнейшей работе над проектами.

## Что устанавливает и настраивает скрипт
### Обновление системы:
- обновляет и подготавливает Ubuntu 24.04 (`update && upgrade && autoremove`) для установки утилит.

### Безопасность:
- заменяет порт входа на сервер `22` на нестандартный;
- запрещает вход на сервер под `root’том` и создаёт нового пользователя;
- добавляет схему входа «`Пароль + Google Authenticator (2FA`)»;
- настраивает `файрвол`;
- закрывает почтовые порты (25, 465, 587, 2525), чтобы злоумышленники не смогли использовать ваш сервер для рассылки спама;
- для защиты от брутфорса устанавливает и настраивает `Fail2ban`;

### Автоматическое обслуживание системы:
- устанавливает `unattended-upgrade`, чтобы критические патчи безопасности ОС ставились автоматически в фоновом режиме;
- для мониторинга логов (`Logwatch`) - настраивает ежедневные отчеты о состоянии системы, сохраняет их в архив и для экономии места на диске удаляет отчёты старше `30 дней`;
- для защиты диска от переполнения запускает в фоновом режиме задачу, которая следит за свободным местом на диске. Если свободного пространства останется менее `15%`, скрипт автоматически очистит системные кэши (`apt`), старые журналы (`journalctl`) и временные файлы.
