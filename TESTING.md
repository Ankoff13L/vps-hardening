# Руководство по проверке и тестированию сервера (Post-Deployment Audit)

После запуска `hardening.sh` вы можете вручную проверить корректность работы всех установленных служб и компонентов с помощью следующих команд.

---

## 1. Файервол (UFW)
Проверьте статус брандмауэра и список открытых портов:
```bash
sudo ufw status verbose
```
- Ожидаемый результат: Статус `active`, входящие соединения по умолчанию заблокированы (`deny`), а ваш кастомный `SSH-порт` и разрешенные порты находятся в списке `ALLOW`.

## 2. Защита от брутфорса (Fail2ban)
Проверьте работу демона и активность защиты SSH:
```bash
sudo fail2ban-client status
sudo fail2ban-client status sshd
```
- Ожидаемый результат: В списке джейлов присутствует `sshd`, счетчик активных банов работает.

## 3. Автоматические обновления безопасности (Unattended-upgrades)
Проверьте статус службы автообновлений:
```bash
sudo systemctl status unattended-upgrades
```
Запустите тестовый прогон (симуляцию) для проверки репозиториев:
```bash
sudo unattended-upgrades --dry-run --debug
```

## 4. Аудит логов (Logwatch)
Проверьте, создаются ли ежедневные отчеты безопасности:
```bash
ls -la /var/log/logwatch_reports/
```
При необходимости запустить генерацию отчета вручную:
```bash
sudo /etc/cron.daily/custom-logwatch
```
## 5. Мониторинг и очистка диска
Проверьте текущее заполнение корневого раздела:
```bash
df -h /
```
Тестовый ручной запуск скрипта очистки (сработает только если диск заполнен более чем на 85%):
```bash
sudo /usr/local/bin/vps-disk-cleanup.sh
```
Проверка наличия задания в планировщике `cron`:
```bash
ls -la /etc/cron.d/vps-disk-cleanup
```
